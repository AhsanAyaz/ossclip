# apps/studio (dormant until Phase 1)

This directory will host the ossclip studio — the chat-driven UI with the preview
player, moment chips and editable layers — scaffolded from the
[BuilderIO/agent-native](https://github.com/BuilderIO/agent-native) starter, per
`BRAINSTORM.md` §5.4 and §7-6.

Note: the npm package named `agent-native` is an unrelated project; Builder.io's
framework is scaffolded from its GitHub repository. Phase 0 deliberately ships no
studio — the CLI (`apps/cli`) is the only interface.
