## How it works (the 30-second mental model)

Sounds live in packs; each sound's `whenToUse` sentence becomes a menu line in
the placement LLM's prompt (the SCENE_REGISTRY pattern). The model places at
word indices (optionally `sceneId` for entrance-sync), a deterministic pass
enforces density (2/4/8 per minute by `--sfx-level subtle|normal|meme`),
spacing (1.5s) and the meme gate. Cues resolve through the TimeMap, mix inside
Remotion so loudnorm measures the full signal. User edits live in
overrides.json and outrank everything. Cache key includes the library metadata
hash — editing a `whenToUse` or the prompt version re-places automatically.

## Traps (new this session)

- **Word index spaces are not interchangeable.** Placements index the
  REPAIRED (and clip-sliced) transcript; `transcript.json` is raw whisper.
  `GET /api/sfx/plan` rebuilds the repaired list server-side —
  `production.transcript` is ALREADY the clip slice, so applyRepairs alone is
  the reconstruction; adding the clip window again double-offsets (the Phase 4
  agent caught this in my own spec).
- **ffmpeg `-progress` `out_time_ms` is MICROseconds** (pinned by test since
  0.1.34, restated because it will bite again).
- **A pre-`--sfx` beatsheet cache has no moments** — produce warns and skips
  SFX; the fix is a re-plan, which regenerates graphics (nondeterministic).
  Warn the user before deleting `scenes-*.json`; note `rm scenes-*.json` also
  globs `scenes-reviewed.json` (harmless — rewritten on next editor render —
  but startling).
- **Concurrent executors + `git stash` don't mix.** An agent stashed to
  bisect causality while another agent was writing the same tree; it went
  fine and it self-reported, but the window was real. Sequence agents that
  share files; parallel only on disjoint file sets.
- The executor agent definitions now enforce the wizard rule; trust the
  reports' "wizard tier" section rather than re-checking by hand.
